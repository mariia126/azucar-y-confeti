# Azúcar y Confeti

Web de Azúcar y Confeti: dulce, salado y decoración de eventos.

Es una página estática: un solo archivo `index.html`, sin instalación ni dependencias.

## Cómo editarla
- Teléfono, correo e Instagram: busca `+34 600 000 000`, `hola@azucarconfeti.es` y `@azucarconfeti` en `index.html`.
- Galerías (Dulce, Salado, Decoración): están en el bloque `var G={...}` al final del archivo.
